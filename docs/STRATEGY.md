# 投資策略與研究判斷

## 策略目標

Evidence-Driven Asymmetric Momentum 結合產業深度研究、基本面預期差、催化劑與市場動能。ETF 名稱、主題與公開宣告以 [公開說明書](../ETF投資策略說明文檔.md) 為準。策略可應用於不同產業，不把 AI、半導體或某個供應鏈題材視為固定的投資範圍。

競賽初賽優先提高期末 NAV，NAV 相同再比較 MDD。風險管理用來降低重大損失、集中度與不必要成本，並非承諾沒有回撤。個人研究沿用同一證據與決策框架，但與競賽狀態隔離。

## 雙向發掘

Research → Quant 從「技術／需求變化 → 瓶頸 → 解決方案 → 候選公司 → 財務敏感度」建立待驗證假說，再觀察相對強弱、成交量及市場認知。技術上可能受惠只代表待驗證路徑，不能直接認定取得訂單、通過驗證或開始量產。

Quant → Research 掃描完整合格股票池，對異常量價、相對強勢或動能加速建立反向研究任務。找不到公開解釋時必須記錄未知；純量化候選仍可依自身可驗證規則參與配置，不需要補寫故事。

多輪研究應持續追問訂單、驗證、量產、UPH／良率、競爭者、相關營收占比、既有市場預期及可驗證事件，同時受時間、候選數與模型呼叫預算限制。這些是研究問題，並不預設每個問題都有可取得答案。

## 研究訊號

| 面向 | 判斷內容 |
| --- | --- |
| 證據強度 | 來源是否合法、原始、可核對，是否存在獨立交叉佐證 |
| 基本面預期差 | 新資訊相較哪個明確基準發生變化 |
| 催化劑接近度 | 事件時間、驗證條件及不確定性；沒有日期則明確保留未知 |
| 新穎性 | 新增事實、同事件更新或舊聞轉載，避免重複加分 |
| 市場認知 | 相對報酬、量價與同業變化是否開始反映資訊 |
| 下行／論點風險 | 競爭、商業化延遲、估值、集中度與論點失效條件 |

沒有合法市場 consensus 時，只能明示使用公司指引、歷史趨勢或其他代理基準，不能把代理比較稱為市場一致預期。催化劑可按 1／5／10／20 個交易日與更長期觀察，但不因此固定持有期間。

具來源、反方檢驗、完整情境與風險記錄的質性研究可進入 early_validation 小額試探，不要求先編造數值共識，也不因此視為已確認加速；沒有可驗證數值預期差不取得其排序加分。

重要假說保存 Bull／Base／Bear 情境、關鍵假設、可能驅動因素、支持與反方證據，以及下一個問題。不硬生成精確成功機率，不用未校準的 LLM 信心直接套 Kelly 部位公式。

## 量化與融合

既有動能、成交量、品質、成長、低波動因子保留為 baseline。啟用因子仍檢查公開說明書語意；每個訊號保留 as-of time，缺值不能被當成真實零成長或零波動。Q0／H1／H2 使用一致的量化排名以隔離研究增量；`quant_ranking: legacy_baseline` 將原公開說明書因子分數轉為橫斷面百分位，獨立的 5／10／20／60 日訊號另行觀察，不任意混成固定加權分數。額外訊號僅在所需歷史、產業或 OHLC 資料足夠時才計算，缺資料即明示 unavailable。

融合採可追溯的證據條件與排序，區分早期探索、初步驗證、加速確認、擁擠及論點失效。研究強度不能繞過價格、流動性、風險或競賽上限；也不要求每筆研究機會都等待突破才允許探索。初始係數與閾值是 **Heuristic Default**，須透過 Forward Testing 校準，不能宣稱最優。

## 動態配置與成本

每天重新比較持股與替代機會，不只是挑最高分的固定 24 檔。延續既有部位、無交易帶、換股成本、下行風險、產業與相關性暴露共同影響決策。分數略高不構成必然換股理由。最終配置先滿足現金、持股數、個股／產業上限與 Active Share，再由 Python 推導整張委託。

目前相關性限制對每一對高相關持股控制合計權重，並以平均相關性作風險折減；它不等於整個相連產業群的總曝險限制。H2 以提供情境中的最差下行估計約束配置，沒有足夠情境或反方檢視時維持探索性上限。這些可解釋規則不代表已校準的機率或統計最優組合。

正式限制依 Repository 官方文件及已確認設定執行。每日最多 25 次是送件次數，使用者提供的新 Schema 允許最多 60 筆 orders／decisions，策略預設仍採 30 筆上限控制交易；兩者不能混為一談。股票池必須固定為官方 150 檔，研究圖譜本身可涵蓋全球公司。

## Forward 比較與學習

Q0 是量化 baseline，H1 結合研究，H2 再納入反方與不確定性部位管理。三者使用相同初始資金、資料截止、股票池、費率與模擬成交方法，帳本各自獨立。觀察 NAV、MDD、換手、成本及到期預測；缺 benchmark 時相對報酬應保持未知。

錯過機會的歸因只能使用當時已封存資料。區分發掘、資料覆蓋、研究、時機、組合限制與不可預測事件，不因事後看到漲幅就宣稱原本可預知。Fixture／Mock 結果只能證明程式路徑，不能證明策略具備 alpha。
